# LiveView Async Loads — Spawn Sites, Message Shapes & Stale Guards

Reference inventory behind `apps/evo_dash/lib/evo_dash_web/live/CONTEXT.md` ("Async data-load & exit-safety contract").
Every read that can cost an `:erpc` round-trip or a task-store `GenServer.call` runs in a supervised `EvoDash.TaskSupervisor` child through `EvoDash.SafeCall.run/1` and lands as a self-message guarded by a monotonic seq/generation counter plus a node match (usually with a project-path / task-id / scope match too); every per-click mutation is either a guarded `SafeCall.run/1` in the handler or a supervised `SafeCall.start/3,4` task whose result message is ALWAYS sent.
A multi-element tuple tag is sent VERBATIM, so `{:foo, seq, node}` arrives as `{{:foo, seq, node}, result}`; tasks spawned with `Task.Supervisor.start_child` + a manual `send/2` have FLAT tags.
Exact message shapes and envelopes: the child CONTEXT.md of each page.

- **ProjectsLive** — `AsyncLoad.maybe_spawn/2` (ONE batch per connected `handle_params`), `Notifications`, VCT / clear-history / foreign-repo paths, `GitHub`; messages `{:async_project_load, node, prev_node_id, path, results}`, `{:task_notifications, seq, node, result}`, `{:projects_loaded, seq, node_id, node, result}`, `{:foreign_repos_restored, task_id, node, result}` and the `{:github_*_result, …}` family; guards `projects_load_seq` + target id + node + active path, `task_notifications_seq`, `projects_seq`/`clear_history_seq` + node, task_id + node, and for GitHub target id + node + path + unique request token (+ issue number), with pending targets and unscoped results rejected.
- **TasksLive** — `PageLoad.start/3`; `TaskDetail` (`ensure/2`, `retry/2`, `load_archive/2`, `load_more_archive/2`, `load_agent_result/3`); messages `{:tasks_page_loaded, seq, node, result}`, `{:task_detail_loaded, seq, node, task_id, result}`, `{:task_archive_loaded, …}`, `{:task_archive_agent_loaded, …}`; guards `page_load_seq` (older seq dropped) + node and `task_detail_seq` + entry seq + task_id + node.
- **ReviewLive** — `ArchiveLoad` (`ensure_loaded/1`, `load_more/1`, `load_agent_result/2`), `LoadData`, `MergeCheck`, `Actions` (merge / reject / resume / ignore / create_pr / extract_skills / auto_resolve); messages `{:review_archive_loaded, task_id, node, seq, offset, result}`, `{:review_archive_agent_loaded, …}`, `{:review_data_loaded, task_id, node, gen, result}`, `{:merge_check_result, task_id, node, repo_id, target, result}`, `{:review_action_result, task_id, node, action, ref, result}`; guards `archive_seq`/`archive_agent_seq` + task_id + node, `load_generation`, repo_id + target, `action_seq` ref vs `@review_action` + node.
- **SystemLive** — self-check / OS / paused / sample seed / source, plus controls via `SafeCall.start/4` (NESTED tags); messages `{:system_checks_result, result}`, `{:platform_os_result, node, os}`, `{:paused_state, node, paused}`, `{:system_samples_seeded, seq, node, result}`, `{{:scheduler_action_result, node, action}, result}`, `{{:system_action_result, node, action}, result}`, `{{:update_force_kill_done, node}, result}`; guards `chart_seed_seq` (+ one 3 s retry) / `source_status_seq` / node.
- **SettingsLive** — scoped node-data loader / `ConfigSave` / custom tools / credentials, plus the persisted-selection connection test via `SafeCall`; messages `{{tag, seq, scope}, node, category_param, result}`, `{{:settings_config_saved, token, scope}, result}`, `{:custom_tools_loaded, node, result}`, `{{:credentials_saved, node, credential_key}, result}`, `{{:llm_test_result, seq, scope}, result}`; guards config loads generation + target/BEAM-node scope, saves owned token + full scope, other loaders node, tests `llm_test_seq` + target/BEAM-node/selection scope + testing state.
- **HomeLive (+ `ApprovalWorkflow`)** — chat lookup / history / task / model select / source gate, plus approval recovery + response via `SafeCall.start/4`; messages `{:chat_agent_lookup, node, seq, task_id, stream_seq, agent}`, `{:chat_history_loaded, node, seq, agent_id, stream_seq, result}`, `{:chat_task_loaded, node, seq, task_id, task}`, `{{:model_select_loaded, seq, node}, result}`, `{{:approval_pending_loaded, seq, scope}, result}`, `{{:approval_workflow_response, seq, scope, request_id}, result}`; guards `chat_fetch_seq` + stream generation/watch ownership, `chat_task_fetch_seq`, `model_select_seq`, `source_check_seq`, and approvals monotonic tokens + chat/node/task/agent scope (nested tags into `recovered/3` / `responded/3`).
- **WelcomeLive** — scoped draft connection test via `SafeCall`; message `{{:welcome_llm_test_result, seq}, guarded_result}`; guard `llm_test_seq` invalidated by draft/node changes + local-only node context.
- **AgentsLive** — page load / refresh / history / commit graph; messages `{:agents_data_loaded, node, gen, result}`, `{:agents_refresh_result, seq, node, result}`, `{:agent_history_loaded, agent_id, node, history_seq, watch_token, result, index}`, `{:commit_graph_loaded, node, seq, result}`; guards `load_generation`, `refresh_seq`, `commit_graph_seq`, `inspector_history_seq` + watch token + selection + node.
- **`LiveHooks.NodeAware` (sidebar)** — `request_tasks_load/2` (connected only, 300 ms debounce) and `request_session_list_load/1` → `SessionList.spawn_load/2` (connected LOCAL mount, every `assign_node/2` context change, every `:node_aware_reload_tasks` debounce); messages `{:node_aware_active_tasks, seq, node_id, node, result}` and the NESTED `{{:session_list_loaded, seq, node}, result}`; guards `:tasks_load_seq` + node (hub-seeded from `EvoDash.ActiveTasks`) and `session_list_seq` + node, applied by `SessionList.applied/4` (a failure keeps the shown rows and records `session_list_error`).
- **Review in-progress UI is part of that contract** — `ReviewComponents.RepoCards.repo_cards/1` takes `review_action` + `busy_repos`, so any in-flight action disables `#merge-all-repositories` and that card's `merge`/`reject`; `ReviewComponents.Actions.task_actions/1` disables every task-level action (`disabled={@loading}`; anchors get `pointer-events-none opacity-50`).
