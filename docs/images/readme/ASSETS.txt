README visual assets

These original vector diagrams follow the Genesis website's black, grey and
brand-red palette and its recursive-work / accepted-history narrative.
They are conceptual illustrations, not screenshots or experimental records.

recursive-world.gif: 12-second looping sequence (960 x 580).
recursive-world.png: static alternative for prefers-reduced-motion.
recursive-world.svg: editable vector version of the completed diagram.
architecture.svg: compact horizontal architecture diagram (960 x 278), with
distinct desktop, dashboard and runtime icons; architecture-mobile.svg stacks
the same layers vertically (540 x 520).
architecture.png: raster version for previews and sharing.
*-mobile: portrait variants for viewports at or below 600 CSS pixels.
The mobile GIF has its own static PNG fallback for reduced-motion preferences.
recursive-world-inline.*: compact diagram for the text/GIF layout, with transparent
side gutters. The README floats it at 400px; narrow pages wrap the text below it.

genesis-agent-history-light.avif / genesis-agent-history-dark.avif: theme-aware
README recordings of the EvoX portal's original recursive-agent Git animation.
Each is 1440 x 960, 30 FPS, 876 frames / 29.2 seconds, with an infinite loop.
Two episodes show accepted merges and a rejected nested branch. English state
captions are included; playback controls are omitted. Matching PNGs show the
resolved first episode for reduced-motion and unsupported-AVIF fallbacks.
The source renderer lives in evox-portal/src/components/art/paradigm-scenes.ts
and recursive-agents.ts. These are conceptual illustrations, not agent logs.

Rebuild the legacy SVG/GIF assets with Node.js, sharp and Python Pillow installed:
  node render.mjs sharp /path/to/temporary-frames
  python encode.py /path/to/temporary-frames

The first render.mjs argument may also be an absolute path to the sharp module.
The frame directory must be dedicated to this animation and contain no other PNGs.
Only final assets and source scripts belong in the repository; do not commit frames.
